# קוראים בכיף – לימוד קריאה לכיתה א'

אפליקציית Next.js + React ללימוד קריאה נכונה בעברית לכיתה א', בממשק ידידותי לילדים (RTL, ניקוד מלא).

## מה יש באפליקציה
| עמוד | תיאור |
|---|---|
| 🔤 אותיות | 22 האותיות, שם האות, מילה לדוגמה, אותיות סופיות והקראה |
| 🎵 ניקוד | בניית הברות מאות + תנועה, ו"רכבת הברות" לתרגול קריאה ברצף |
| 🧩 מילים | קריאת מילה הברה-הברה בצבעים, ואז כמילה שלמה |
| 📖 סיפורים | סיפורים קצרים מנוקדים עם הקראה ומעקב מילה-מילה |
| 🎮 משחק | התאמת תמונה למילה, ושמיעת שם אות ומציאתה |
| 🎤 בדיקת קריאה | הילד/ה קורא/ת בקול והמחשב בודק אם הקריאה נכונה (זיהוי דיבור) |
| 📊 דוח התקדמות | אילו אותיות ומילים הילד/ה שולט/ת בהן ואילו צריך לתרגל |

### איך עובדת בדיקת הקריאה
- הילד/ה לוחץ/ת על המיקרופון וקורא/ת את האות (בשם שלה, למשל "גימל") או את המילה.
- הדפדפן מזהה את הדיבור בעברית (`he-IL`), הטקסט מנורמל (בלי ניקוד, אותיות סופיות מאוחדות) ומושווה לתשובה הנכונה, עם סובלנות קטנה לשגיאות זיהוי.
- שני ניסיונות לכל פריט. אחרי טעות שנייה האפליקציה מקריאה את התשובה הנכונה.
- אותיות שצריך לתרגל מופיעות ראשונות בסבב הבא.
- **בדיקה ע"י מבוגר**: אם הדפדפן לא תומך בזיהוי דיבור (למשל Firefox), הורה או מורה מסמנים "קרא נכון" / "עוד לא".
- ההתקדמות נשמרת בדפדפן (localStorage).

> זיהוי דיבור עובד הכי טוב ב-Chrome או Edge, ודורש אישור גישה למיקרופון (ב-localhost או באתר https).

## האתר ב-GitHub Pages
כתובת: **https://amal-ramot.github.io/reading-study/**

הפרסום אוטומטי: בכל push ל-`main` (או לענף הפיתוח) ה-workflow `.github/workflows/deploy-pages.yml` בונה את האתר כאתר סטטי ומעלה אותו.

הגדרה חד-פעמית: במאגר ב-GitHub נכנסים ל-**Settings → Pages**, ותחת **Build and deployment → Source** בוחרים **GitHub Actions**.
אחרי זה מריצים מחדש את ה-workflow (Actions → Deploy to GitHub Pages → Run workflow).

## הרצה מקומית
```bash
npm install
npm run dev
```
ואז פותחים בדפדפן: http://localhost:3000

לגרסת production:
```bash
npm run build && npm start
```
